# Практическая работа 2, вариант 27

Инструмент построения графа зависимостей npm на Python 3.9 или новее.
Этап 1 читает YAML-конфигурацию, проверяет её и выводит все настройки
в формате `ключ=значение`. Получение зависимостей и построение графа
относятся к следующим этапам.

`load_config()` читает и проверяет настройки; `main()` разбирает путь к
конфигурации, показывает значения и возвращает код завершения. При ошибке
приложение выводит сообщение в stderr без traceback.

## Установка, запуск и тесты

Сборка отдельного файла не нужна. Установи библиотеку для чтения YAML:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
./run.sh --config config.yaml
make check
```

`--config` задаёт путь к YAML-файлу. Без этой опции `run.sh` использует
`config.yaml` из корня проекта. Скрипт можно вызвать из другой папки.
Все пять рабочих настроек берутся только из YAML; командная строка
выбирает сам файл конфигурации. Также доступны `make run` и `make test`.

## Настройки

| Ключ | Значение |
| --- | --- |
| `package_name` | Имя пакета npm (`express`, `@scope/name`). В тестовом режиме — только заглавные латинские буквы (`A`). |
| `repository` | HTTP(S) URL реестра npm. В тестовом режиме — путь к существующему файлу репозитория; относительный путь считается от YAML-файла. |
| `test_mode` | YAML-значение `true` или `false`: использовать локальный тестовый репозиторий или реальный URL. |
| `output_file` | Имя будущего PNG-файла с графом, например `graph.png`. На этапе 1 файл не создаётся. |
| `ascii_tree` | YAML-значение `true` или `false`: включить ASCII-дерево зависимостей на этапе визуализации. На этапе 1 значение только выводится. |

Пример конфигурации находится в `config.yaml`:

```yaml
package_name: express
repository: https://registry.npmjs.org
test_mode: false
output_file: graph.png
ascii_tree: false
```

Пример запуска:

```text
$ ./run.sh
package_name=express
repository=https://registry.npmjs.org
test_mode=false
output_file=graph.png
ascii_tree=false
```

Тестовый режим можно проверить командой
`./run.sh --config examples/test-config.yaml`. Путь к тестовому
репозиторию будет выведен как абсолютный. Файл
`examples/test-repository.yaml` пока служит только для проверки пути.

## Ошибки конфигурации

Приложение сообщает об ошибке в stderr и завершает работу с кодом `2`.
Проверки покрывают каждый параметр и сам YAML-файл:

| Параметр | Пример ошибки |
| --- | --- |
| `package_name` | `bad package` или `a` в тестовом режиме |
| `repository` | `not-a-url` в обычном режиме или отсутствующий файл в тестовом |
| `test_mode` | `maybe` вместо логического значения |
| `output_file` | `graph.svg` вместо имени PNG-файла |
| `ascii_tree` | `1` вместо логического значения |
| YAML-файл | Нет файла, неверный синтаксис или отсутствует обязательный ключ |

Например, после замены `output_file: graph.png` на
`output_file: graph.svg` в копии конфигурации:

```text
$ ./run.sh --config bad-config.yaml
Ошибка: output_file: ожидается имя PNG-файла
```

Все перечисленные случаи проверяются автоматическими тестами в `tests/`.
Код находится в `main.py` и `src/dependency_graph/`.
